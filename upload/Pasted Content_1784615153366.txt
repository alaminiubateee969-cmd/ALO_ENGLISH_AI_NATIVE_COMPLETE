# UNIVERSAL PRODUCTION WEB APPLICATION MASTER SPECIFICATION

Use this specification for every CRM, ERP, SaaS platform, LMS, AI system, hosting control panel, automation platform, marketplace, portal, dashboard, internal system, or modern web application.

The generated application must be complete, secure, production-ready, testable, maintainable, environment-driven, and deployable without modifying source code.

---

# 5. CONFIGURATION MODULE

Create a centralized typed configuration module.

Example:

```ts
import { z } from "zod";

const envSchema = z.object({
  NODE_ENV: z.enum(["development", "test", "production"]),
  PORT: z.coerce.number().int().positive(),
  HOSTNAME: z.string().min(1),
  APP_NAME: z.string().min(1),
  APP_URL: z.string().url(),
  DATABASE_URL: z.string().min(1),
  AUTH_SECRET: z.string().min(32),
});

export const env = envSchema.parse(process.env);
```

Do not access `process.env` randomly throughout the codebase.

Use the validated configuration module.

# 6. SERVER CODE STANDARD

Never write:

```ts
const PORT = 3100;
const HOST = "0.0.0.0";
const API_URL = "https://example.com";
```

Always use validated environment configuration:

```ts
const port = Number(process.env.PORT);
const hostname = process.env.HOSTNAME || "127.0.0.1";
```

Preferred:

```ts
import { env } from "@/lib/config/env";

const port = env.PORT;
const hostname = env.HOSTNAME;
```

Application ports must bind to:

```text
127.0.0.1
```

unless a containerized internal network explicitly requires another binding.

Never expose Node.js, Python, or application runtime ports directly to the public internet.

# 26. ERROR HANDLING

* Stack traces
* Database internals
* File-system paths
* Environment variables
* Secret values

```ts
try {
  // operation
} catch (error) {

  return Response.json(

      status: 500,
      success: false,
      message: "An unexpected error occurred.",
      data: null,
      error: {
        code: "INTERNAL_SERVER_ERROR"
      }

    { status: 500 }

}
```

Use typed application errors:

* ValidationError
* AuthenticationError

* NotFoundError
* ConflictError
* RateLimitError
* ExternalServiceError
