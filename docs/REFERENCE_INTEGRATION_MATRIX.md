# Reference Integration Matrix

**Audit date:** 2026-10-10  
**Report status:** BLOCKED for exam-content readiness; official references below are format references only, not permission to reproduce exam material.

## Policy and source handling

Official sources were reviewed to establish current product identity and broad format constraints. No official question bank, answer key, recording, or protected test content was imported by this audit. Existing legacy seed prompts do not have a content-origin/license manifest; their provenance is **NOT VERIFIED**. Do not represent a seed item as official, endorsed, repeated, or full-length because it resembles an official task. Use original or explicitly licensed content, record its source and permitted use, and have it reviewed by qualified subject-matter experts.

The code currently has 20 exam-type metadata codes in `prisma/seed.mjs`. An exam-type row is not an integration. The default `npm run prisma:seed` now creates core metadata only and intentionally does not seed synthetic question banks.
