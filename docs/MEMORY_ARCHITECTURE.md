# Memory Architecture

## 10-Layer Memory
L1 Session → L2 Attempt → L3 Learning → L4 Long-Term → L5 Exam Knowledge
L6 Question Knowledge → L7 Agent Memory → L8 Model Performance → L9 Engineering → L10 System Experience

## Privacy Isolation
Student A memory ≠ Student B memory.
All memory functions take userId and filter by it.
verifyPrivacyIsolation() tests for cross-user leakage.

## Data-Driven Recommendations
Weaknesses derived from actual Score records.
No hardcoded "weakness" messages.
Trend analysis: improving/stable/declining based on score history.
