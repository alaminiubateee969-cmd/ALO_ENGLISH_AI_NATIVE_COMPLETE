# Model Routing

Multi-provider routing abstraction.
Tasks: writing_evaluation, speaking_evaluation, interview_simulation, question_generation,
question_validation, summarization, personalization, memory_extraction, self_improvement, reasoning.
Providers: Groq, OpenRouter, Gemini, HuggingFace, local rule engine.
Fallback: every task falls back to local rule engine (always available, no API key needed).
