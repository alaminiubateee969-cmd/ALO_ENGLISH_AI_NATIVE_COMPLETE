as it was on the date in the folder name, and parts of it describe infrastructure
that has since been retired.

Documents are archived rather than deleted because an audit's value is that it
records what was true, what was checked, and what was asked of the owner at a
point in time. Deleting it loses that. Presenting it as current loses more.
