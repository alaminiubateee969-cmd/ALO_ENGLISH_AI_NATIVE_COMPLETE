# Self-Development

## Controlled Self-Improvement Loop
detect → diagnose → create candidate fix → sandbox → test → benchmark →
security scan → regression test → quality comparison → approval policy → deploy

## Safety
- canAutoDeploy: FALSE (human approval always required)
- All changes go through quality gates
- 10 gates must pass (functional, test, regression, security, latency, cost, AI quality, student outcome, model agreement, prompt stability)
- Overall score must be >= 80 to deploy
