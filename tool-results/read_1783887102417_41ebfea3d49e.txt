    11→## 0. How to Read This Guide
    12→
    13→This guide has three layers:
    14→
    15→1. **Global guidance** (§1–§5) — applies to every exam: equipment, before/during/after workflow, scoring interpretation, disclaimers.
    16→2. **Per-exam reference** (§6) — one compact entry per exam with: what it is, who should take it, sections, time, question types, scoring style, mock-start steps, speaking/recording notes, writing-evaluation notes, report interpretation, post-score actions, official-exam disclaimer.
    17→3. **Compliance wording** (§7) — the exact labels and disclaimers used on every public surface.
    18→

    23→## 1. Equipment Guide
    24→
    25→### 1.1 Recommended setup
    26→
    27→| Item | Requirement | Notes |
    28→|---|---|---|
    29→| Device | Laptop or desktop recommended | Mobile (phone/tablet) supported for **practice only**; the layout is responsive but some reading passages are easier on a larger screen |
    30→| Operating system | Windows 10+, macOS 11+, ChromeOS, recent Linux | Mobile: iOS 15+, Android 11+ |
    31→| Browser | Latest Chrome, Edge, Firefox, or Safari | Update within the last 90 days; avoid IE and beta/dev channels |
    32→| Internet | Stable 5 Mbps+ download / 1 Mbps+ upload | Use wired or strong Wi-Fi; avoid metered hotspot for long exams |
    33→| Microphone | Required for any speaking practice | Built-in laptop mic works; USB headset mic is better. Browser prompts for mic permission — click "Allow" |
    34→| Camera | Optional for most exams; recommended for interview-style practice | Used only for the *optional* Practice Interview Coach self-review; never recorded silently |
    35→| Headphones | Recommended for listening sections | Avoids echo and prevents audio leakage in shared rooms |
    36→| Room | Quiet, well-lit, free of interruptions | Close chat apps, mute phone notifications |
    37→| Power | Laptop plugged in | Long exams (MCAT, IELTS) drain battery |
    38→| Time | Uninterrupted block matching the exam duration + 5-minute buffer | Buffer is added by `exam_settings.attempt_default_buffer_minutes` |
    39→
    40→### 1.2 Browser pre-flight (auto-run on attempt start)
    41→
    42→The platform runs a quick pre-flight on every attempt start screen:
    43→
    44→1. Browser version check (rejects IE; warns on out-of-date browsers).
    45→2. Microphone permission check (for speaking exams).
    46→3. Network RTT check (warns if > 300 ms).
    47→4. Screen size check (warns if < 768×600 px).
    48→5. Storage quota check (warns if IndexedDB / localStorage are unavailable — autosave needs them).
    49→
    50→A failed pre-flight does not block practice, but the student is asked to acknowledge the warning before continuing.
    51→
    52→### 1.3 Mobile support
    53→
    54→- Mobile is supported for **practice only** and works best for short exams (Duolingo, Linguaskill, OIETC, ALO Diagnostic, visa interviews).
    55→- For long reading-dense exams (IELTS Reading, SAT R&W, MCAT CARS, LSAT RC) a laptop/desktop is strongly recommended.
    56→- Speaking recording works on mobile browsers but the timer + passage layout is more comfortable on a larger screen.

    60→## 2. Before the Exam
    61→
    62→### 2.1 Account setup (first time only)
    63→
    64→1. **Register** at `/register` with name, email, phone, password.
    65→2. **Verify email** — click the link in the verification email. The account stays in `status = 'pending'` until verified.
    66→3. **Verify phone** — enter the OTP sent by SMS. Required before any attempt.
    67→4. **ALO students**: enter your ALO Student ID (optional) to unlock the **3 free ALO attempts**. Without it, you get **1 free public attempt**. The check is server-side; the ID is validated against the ALO CRM during the hourly CRM sync.
    68→5. **Accept terms** — the current Terms of Service (`exam_settings.terms_version`) and Privacy Policy (`privacy_version`). Stored in `exam_terms_acceptance`.
    69→
    70→### 2.2 Check your free quota
    71→
    72→Visit the Student Dashboard → **Free Quota** card. It shows:
    73→
    74→- `used_free_attempts` / `max_free_attempts` (depends on ALO/public/partner/ambassador flags).
    75→- A note that the quota is **shared across all 32 exams**.
    76→- A "Buy paid attempt" / "Redeem voucher" button shown only when the free quota is exhausted.
    77→
    78→The number you see is a snapshot. The authoritative check happens at attempt start — if another device used a slot in the meantime, the start call may still fail.
    79→
    80→### 2.3 Select the exam
    81→
    82→From the public exam catalog (`/exams`) or from the Student Dashboard → **Practice Tests**:
    83→
    84→1. Filter by category (English / Study Abroad / University / Visa / ALO Internal) or search.
    85→2. Open the exam landing page to read its sections, duration, scoring scale, and disclaimer.
    86→3. Click **Start Digital Practice Session**.
    87→
    88→### 2.4 Read the instructions and disclaimer
    89→
    90→Every attempt start screen shows:
    91→
    92→- The exam name and the wording *"X-style practice test"*.
    93→- The number of sections, total questions, total duration.
    94→- The free-quota cost of this attempt (1 slot unless already exhausted).
    95→- The **practice disclaimer** (canonical text from `exam_settings.practice_disclaimer`):
    96→  > *This is an original practice question created by ALO. It is not an official exam item and is not affiliated with, endorsed by, or reproduced from any official test publisher. Items will not appear in any real exam.*
    97→- A checkbox: *"I understand this is a practice exam only and the score is an estimate."*
    98→
    99→The Start button is disabled until the checkbox is ticked.
   100→
   101→### 2.5 Test the microphone (speaking exams only)
   102→
   103→- Click **Test microphone** on the start screen.
   104→- Speak a 5-second sample; the platform plays it back.
   105→- If no audio is captured, check the browser mic permission and the OS mic level.
   106→- The mic test writes a `device_check` row to `exam_proctor_logs` for auditability.
   107→
   108→### 2.6 Start the timer
   109→
   110→Click **Start**. The timer starts on the server (`exam_mock_attempts.started_at = NOW()`) and is also displayed at the top of the screen. The server clock is authoritative — the client timer is decorative.

   114→## 3. During the Exam
   115→
   116→### 3.1 Timer
   117→
   118→- Visible at the top of every screen, formatted `HH:MM:SS`.
   119→- Counts down from the exam's total duration + `attempt_default_buffer_minutes` (default 5).
   120→- When 5 minutes remain, the timer turns orange; when 1 minute remains, it turns red.
   121→- When the timer hits zero, the attempt is auto-submitted by the server (`status = 'submitted'`, `submit_reason = 'timeout'`).
   122→
   123→### 3.2 Autosave
   124→
   125→- Every answer is autosaved to `exam_answers` within 2 seconds of the student changing it.
   126→- A "Saved" indicator appears next to each question; if save fails (network drop), the indicator turns red and the student is asked to retry.
   127→- Speaking recordings are uploaded in chunks; if the connection drops, the upload resumes when reconnected.
   128→
   129→### 3.3 Answer all questions; flag the difficult ones
   130→
   131→- The question palette on the right shows answered (green), flagged (orange), and unseen (gray) questions.
   132→- **Flag for review** marks a question for revisit; flagged answers are still graded.
   133→- Use **Previous / Next** to navigate; the palette is clickable.
   134→
   135→### 3.4 Submit before time
   136→
   137→- Click **Submit** at any time. A confirmation modal shows the count of unanswered questions and asks for confirmation.
   138→- On confirm, the attempt moves to `status = 'submitted'` and scoring begins.
   139→
   140→### 3.5 Refreshing the page
   141→
   142→- Refreshing is allowed; the autosaved answers are restored.
   143→- The timer continues from server time, not from the page reload — refreshing does not give extra time.
   144→- If the browser crashes, reopen the same URL within `attempt_expiry_hours` (24h) and resume.
   145→
   146→### 3.6 Integrity
   147→
   148→- Tab switches are logged in `exam_proctor_logs` if `exam_settings.proctoring_enabled = true`. The student sees a warning at `proctor_tab_switch_threshold` (default 3) tab switches. Practice exams do not auto-fail on tab switches — they are practice.
   149→- Camera snapshots (only if the student opted into the Practice Interview Coach self-review) are stored locally and never uploaded without explicit per-attempt consent.

   153→## 4. After the Exam
   154→
   155→### 4.1 View the Smart Score Report
   156→
   157→After submission, the platform renders the **Smart Score Report**:
   158→
   159→- Overall **estimated score** in the exam's native scale (Band 0-9, 0-120, 400-1600, etc.).
   160→- A **CEFR estimate** (A1–C2) for English-proficiency exams.
   161→- **Skill breakdown** bars (Listening / Reading / Writing / Speaking, or Quant / Verbal / etc.).
   162→- **Question review** — each question, the student's answer, the correct answer, and an explanation.
   163→- The practice disclaimer is printed on page 1.
   164→
   165→The report is generated by `app/Services/PdfReportService.php` and stored in `storage/private/reports/<attempt_code>.pdf`.
   166→
   167→### 4.2 Review explanations
   168→
   169→Every question has an `explanation` field authored by ALO's content team. Read each one, even for questions you got right — the explanation teaches the underlying skill.
   170→
   171→### 4.3 Download the PDF
   172→
   173→- Click **Download Smart Score Report (PDF)**.
   174→- The download is a signed URL (`DownloadController::serve()`) with a 60-second TTL and IP pin.
   175→- The disclaimer is on page 1.
   176→
   177→### 4.4 Book a counseling session
   178→
   179→- Click **Book counseling** on the report.
   180→- Pick a slot from the ALO counselor calendar; the booking writes to `exam_consultation_bookings` and syncs to the ALO CRM via the hourly cron.
   181→- Counseling sessions are with ALO advisors, not with official examiners.
   182→
   183→### 4.5 Follow the study plan
   184→
   185→The Student Dashboard → **Study Plan** shows a 7-day plan generated from your weakest skills in the last attempt(s). Each day has 2–3 short tasks (read a passage, practice a question type, watch a 5-min video).
   186→
   187→### 4.6 Retake
   188→
   189→- If you still have free quota, retake is one click.
   190→- If free quota is exhausted, redeem a voucher or pay the per-attempt fee (`paid_attempt_price_usd`).
   191→- Each retake is a new attempt with a new `attempt_code`. The previous report remains available.

   195→## 5. How to Interpret the Estimated Score
   196→
   197→### 5.1 What it is
   198→
   199→The score is an **estimate** produced by `app/Services/ScoringRules.php` using the scoring rule JSON stored on the practice set (`exam_practice_sets.scoring_rule_json`). The rule is one of:
   200→
   201→- **band** — IELTS-style 0–9 in 0.5 increments (Listening, Reading, Writing, Speaking, Overall).
   202→- **scaled** — PTE 10–90, TOEFL 0–120, SAT 400–1600, GRE 130–170, GMAT 205–805, MCAT 472–528, ACT 1–36, OET A–E.
   203→- **percent** — University placement / scholarship tests (0–100).
   204→- **rubric** — Visa/interview and ALO internal exams (Pass/Fail with sub-criteria scores).
   205→- **cefr** — A1–C2 for English-placement and diagnostic exams.
   206→
   207→### 5.2 What it is not
   208→
   209→- It is **not** an official test result.
   210→- It is **not** a guarantee of the score you will receive on a real administration.
   211→- It is **not** comparable across exam families (an IELTS Band 7 is not "the same" as a TOEFL 100 — only the official concordance tables published by the test owners are authoritative).
   212→- It is **not** a substitute for diagnostic feedback from a qualified teacher.
   213→
   214→### 5.3 How to use it
   215→
   216→Use the estimate to:
   217→
   218→1. Track your own progress over multiple attempts.
   219→2. Identify the skill (L/R/W/S, or Quant/Verbal/etc.) that is pulling your overall down.
   220→3. Decide whether to book a counseling session or buy a paid attempt for targeted practice.
   221→
   222→Do **not** use the estimate to:
   223→
   224→1. Claim proficiency on a visa or university application.
   225→2. Compare yourself to a friend who took a different exam family.
   226→3. Substitute for an official test sitting.

   230→## 6. Per-Exam Reference (all 32)
   231→
   232→> Each entry uses the same 12-field template. "Sections" and "Question types" are sourced from `exam_sections` and `exam_question_types`; durations and counts from `exam_sections.duration_minutes` / `exam_sections.question_count`. The disclaimer text is the same for every exam and is reproduced once at the end of the section.
   233→
   234→### 6.1 English Proficiency (11 exams)
   235→
   236→#### 6.1.1 IELTS Academic — `IELTS-ACAD`
   237→- **What it is:** An IELTS-style academic practice test covering the four skills assessed on the real IELTS Academic module.
   238→- **Who should take it:** Students targeting undergraduate or postgraduate admission at institutions that accept IELTS Academic; students planning UKVI Academic sub-category practice.
   239→- **Sections:** Listening (30 min, 40 Q), Academic Reading (60 min, 40 Q), Academic Writing Task 1 (20 min) + Task 2 (40 min), Speaking (11–14 min, 3 parts).
   240→- **Total duration:** ~180 minutes.
   241→- **Question types:** single_mcq, multi_mcq, true_false_notgiven, yes_no_notgiven, matching_headings, matching_paragraphs, matching_sentence_endings, sentence_completion, summary_completion, fill_blanks, short_answer, writing_task1, writing_task2, speaking_part1, speaking_part2, speaking_part3.
   242→- **Scoring style:** Band 0–9 (overall + per-skill) computed by the band scorer.
   243→- **How to start a mock:** Dashboard → Practice Tests → IELTS Academic → Start Digital Practice Session → read disclaimer → tick checkbox → test microphone → Start.
   244→- **Equipment needed:** Laptop/desktop, microphone, headphones (for listening), stable internet, quiet room.
   245→- **Speaking recording:** Browser captures audio via `MediaRecorder`, uploads chunks to `public/uploads/audio/`, master copy moves to `storage/private/audio/`. Auto-graded by the Automated Practice Feedback service on 6 dimensions (fluency, pronunciation, lexical resource, grammar, coherence, task response).
   246→- **Writing evaluation:** Free-text submission; word count enforced (Task 1 ≥150, Task 2 ≥250, max 750). Auto-graded by the ALO Evaluation System rubric; an ALO Practice Examiner may review and add comments in the examiner queue.
   247→- **Report:** Smart Score Report (PDF) with overall band, per-skill band, CEFR estimate, question review, model answers, disclaimer.
   248→- **Interpret estimated score:** Band 9 = expert; 7–8 = good user; 5–6 = modest/competent; below 5 = limited. Treat as a directional estimate only.
   249→- **After score:** Book counseling, follow 7-day study plan, retake after 48–72 hours to measure progress.
   250→- **Official exam disclaimer:** IELTS Academic is a registered trademark of Cambridge University Press & Assessment, the British Council, and IDP Education. ALO's "IELTS-style academic practice test" is not affiliated with, endorsed by, or reproduced from any official IELTS administration.
   251→
   252→#### 6.1.2 IELTS General Training — `IELTS-GEN`
   253→- **What it is:** An IELTS-style General Training practice test for migration and work contexts.
   254→- **Who should take it:** Candidates preparing for migration to the UK, Canada, Australia, or New Zealand under General Training requirements.
   255→- **Sections:** Listening (30 min), General Training Reading (60 min), General Writing Task 1 (letter, 20 min) + Task 2 (essay, 40 min), Speaking (11–14 min).
   256→- **Total duration:** ~165 minutes.
   257→- **Question types:** as IELTS Academic but Reading uses everyday sources (notices, ads, workplace documents); Writing Task 1 is a letter (`writing_task1_general`).
   258→- **Scoring style:** Band 0–9.
   259→- **How to start a mock:** same flow as 6.1.1, pick "IELTS General Training".
   260→- **Equipment needed:** same as 6.1.1.
   261→- **Speaking recording:** same as 6.1.1.
   262→- **Writing evaluation:** same as 6.1.1 but Task 1 uses the letter rubric (tone, purpose, audience).
   263→- **Report:** same shape as 6.1.1.
   264→- **Interpret estimated score:** Band 4 = limited; 5 = modest; 6 = competent; 7+ = good. Migration often requires 6.0–6.5 per skill.
   265→- **After score:** retake after 1 week; book counseling if speaking or writing is below target.
   266→- **Official exam disclaimer:** Same as 6.1.1.
   267→
   268→#### 6.1.3 IELTS for UKVI — `IELTS-UKVI`
   269→- **What it is:** An IELTS UKVI-style practice test mirroring the Secure English Language Test (SELT) format used for UK visas.
   270→- **Who should take it:** Students applying for UK student visas requiring a SELT; candidates who need to practice the in-person SELT format.
   271→- **Sections:** Same four skills as IELTS Academic; speaking is conducted face-to-face in real SELT administration (ALO practice is recorded, not face-to-face).
   272→- **Total duration:** ~180 minutes.
   273→- **Question types:** same as IELTS Academic.
   274→- **Scoring style:** Band 0–9; CEFR-mapped (B1 / B2 / C1) per Common European Framework.
   275→- **How to start a mock:** same flow, pick "IELTS for UKVI".
   276→- **Equipment needed:** same as 6.1.1; camera optional for the Practice Interview Coach self-review of the speaking part.
   277→- **Speaking recording:** same as 6.1.1; the SELT face-to-face format is approximated by recording + Automated Practice Feedback.
   278→- **Writing evaluation:** same as 6.1.1.
   279→- **Report:** Band + CEFR annotation (e.g. "Band 5.5 — CEFR B2").
   280→- **Interpret estimated score:** UKVI Academic requires B2 (Band 5.5) for degree-level; UKVI A1/B1 levels apply to family/spouse visas.
   281→- **After score:** If below the visa threshold, book a counselor and follow the 7-day plan focused on the weakest skill.
   282→- **Official exam disclaimer:** IELTS for UKVI is administered by IELTS SELT Consortium. ALO's "IELTS UKVI-style practice test" is not an official SELT administration and produces no UKVI-recognized score.
   283→
   284→#### 6.1.4 PTE Academic — `PTE-ACAD`
   285→- **What it is:** A PTE-style academic practice test for the computer-based Pearson Test of English.
   286→- **Who should take it:** Students applying to Australian, UK, NZ, and Canadian institutions that accept PTE Academic.
   287→- **Sections:** Speaking & Writing (54–67 min), Reading (29–30 min), Listening (30–43 min).
   288→- **Total duration:** ~120 minutes.
   289→- **Question types:** read_aloud, repeat_sentence, describe_image, retell_lecture, summarize_spoken_text, summarize_written_text, essay, reading_fill_blanks, reorder_paragraphs, listening_fill_blanks, write_from_dictation, multiple-choice (single_mcq, multi_mcq).
   290→- **Scoring style:** Scaled 10–90 (overall + communicative skills + enabling skills).
   291→- **How to start a mock:** Dashboard → Practice Tests → PTE Academic → Start.
   292→- **Equipment needed:** Microphone required (speaking), headphones recommended (listening).
   293→- **Speaking recording:** Same pipeline as 6.1.1; the Automated Practice Feedback service scores pronunciation, oral fluency, and content.
   294→- **Writing evaluation:** Word count enforced; auto-graded on content, form, grammar, vocabulary, spelling.
   295→- **Report:** Scaled 10–90 + sub-skill bars + question review.
   296→- **Interpret estimated score:** 65+ is competitive for most universities; 79+ for top-tier.
   297→- **After score:** Practice the lowest enabling skill (e.g. spelling or pronunciation).
   298→- **Official exam disclaimer:** PTE Academic is a trademark of Pearson Education. ALO's "PTE-style academic practice test" is not affiliated with or endorsed by Pearson.
   299→
   300→#### 6.1.5 TOEFL iBT — `TOEFL-IBT`
   301→- **What it is:** A TOEFL iBT-style practice test for the internet-based Test of English as a Foreign Language.
   302→- **Who should take it:** Students applying to US and Canadian universities, and other institutions that accept TOEFL iBT.
   303→- **Sections:** Reading (54–72 min), Listening (41–57 min), Speaking (17 min), Writing (50 min, integrated + academic discussion).
   304→- **Total duration:** ~117 minutes.
   305→- **Question types:** single_mcq, multi_mcq, sentence_completion, inference, central_idea, vocabulary_in_context, summarize_spoken_text, independent_speaking, integrated_writing, academic_discussion.
   306→- **Scoring style:** Scaled 0–120 (4 sections × 30).
   307→- **How to start a mock:** Dashboard → Practice Tests → TOEFL iBT → Start.
   308→- **Equipment needed:** Microphone, headphones, stable internet.
   309→- **Speaking recording:** Browser records 45–60-second responses; auto-graded on delivery, language use, topic development.
   310→- **Writing evaluation:** Integrated (read + listen + write) and academic discussion; auto-graded on content, organization, grammar, vocabulary.
   311→- **Report:** 0–120 + per-section bars + question review.
   312→- **Interpret estimated score:** 100+ is competitive for top US universities; 79+ for many graduate programs.
   313→- **After score:** Practice the integrated writing task if score < 24.
   314→- **Official exam disclaimer:** TOEFL is a trademark of Educational Testing Service (ETS). ALO's "TOEFL iBT-style practice test" is not affiliated with or endorsed by ETS.
   315→
   316→#### 6.1.6 Duolingo English Test — `DUOLINGO`
   317→- **What it is:** A Duolingo-style adaptive practice test for the Duolingo English Test.
   318→- **Who should take it:** Students applying to institutions that accept DET (many US, UK, and Canadian universities).
   319→- **Sections:** Literacy, Comprehension, Conversation, Production (single adaptive section, ~60 min).
   320→- **Total duration:** ~60 minutes.
   321→- **Question types:** read_and_select, listen_and_type, complete_the_sentence, interactive_reading, describe_image, writing_sample, speaking_sample, fill_blanks.
   322→- **Scoring style:** Scaled 10–160 (with subscores: Literacy, Comprehension, Conversation, Production).
   323→- **How to start a mock:** Dashboard → Practice Tests → Duolingo English Test → Start.
   324→- **Equipment needed:** Microphone, camera (optional, for the speaking sample self-review), stable internet.
   325→- **Speaking recording:** 30–90 second samples; auto-graded on fluency, content, complexity.
   326→- **Writing evaluation:** 3–5 minute writing sample; auto-graded on grammar, lexical diversity, task relevance.
   327→- **Report:** 10–160 + 4 subscores + question review.
   328→- **Interpret estimated score:** 105+ for many US universities; 120+ for top-tier.
   329→- **After score:** Practice production (writing/speaking) if subscore is the lowest.
   330→- **Official exam disclaimer:** Duolingo English Test is a trademark of Duolingo, Inc. ALO's "Duolingo-style practice test" is not affiliated with or endorsed by Duolingo.
   331→
   332→#### 6.1.7 OIETC — `OIETC`
   333→- **What it is:** An OIETC-style practice test for the Online International English Test Certificate.
   334→- **Who should take it:** Students applying to UK universities that accept OIETC as an alternative to IELTS/TOEFL.
   335→- **Sections:** Reading, Listening, Writing, Speaking (4 sections, ~90 min total).
   336→- **Total duration:** ~90 minutes.
   337→- **Question types:** single_mcq, fill_blanks, short_answer, writing_task2, speaking_part1, vocabulary_in_context.
   338→- **Scoring style:** CEFR A1–C1.
   339→- **How to start a mock:** Dashboard → Practice Tests → OIETC → Start.
   340→- **Equipment needed:** Microphone, headphones.
   341→- **Speaking recording:** 2–3 minute Part 1 response; auto-graded.
   342→- **Writing evaluation:** 250+ word essay; auto-graded.
   343→- **Report:** CEFR level + question review.
   344→- **Interpret estimated score:** B2 is typical for undergraduate entry; C1 for postgraduate.
   345→- **After score:** Practice writing if below B2.
   346→- **Official exam disclaimer:** OIETC is administered by participating UK universities. ALO's "OIETC-style practice test" is not affiliated with any official OIETC administration.
   347→
   348→#### 6.1.8 Occupational English Test (OET) — `OET`
   349→- **What it is:** An OET-style practice test for healthcare professionals (medicine, nursing, dentistry, pharmacy, etc.).
   350→- **Who should take it:** Healthcare professionals seeking registration in the UK, US, Australia, Ireland, Singapore, etc.
   351→- **Sections:** Listening (45 min), Reading (60 min), Writing (45 min, profession-specific), Speaking (20 min, role-play).
   352→- **Total duration:** ~165 minutes.
   353→- **Question types:** single_mcq, multi_mcq, fill_blanks, short_answer, writing_task1 (profession-specific letter), speaking_part2 (role-play).
   354→- **Scoring style:** A–E (A = 350–500, B = 320–340, C+ = 300–310, C = 270–290, D = 200–260, E = 100–190).
   355→- **How to start a mock:** Dashboard → Practice Tests → OET → select profession (Medicine / Nursing / etc.) → Start.
   356→- **Equipment needed:** Microphone, headphones.
   357→- **Speaking recording:** Role-play with a pre-recorded interlocutor; auto-graded on intelligibility, fluency, appropriateness, resources of grammar/expression.
   358→- **Writing evaluation:** Profession-specific letter (referral, discharge, transfer); auto-graded on purpose, content, conciseness/clarity, genre/style, organization, language.
   359→- **Report:** A–E grade per skill + numeric (0–500) + question review.
   360→- **Interpret estimated score:** Grade B (350+) is required by most regulators.
   361→- **After score:** Practice role-plays if speaking below B.
   362→- **Official exam disclaimer:** OET is a trademark of Cambridge Boxhill Language Assessment. ALO's "OET-style practice test" is not affiliated with or endorsed by the OET Centre.
   363→
   364→#### 6.1.9 LanguageCert International ESOL — `LANGCERT`
   365→- **What it is:** A LanguageCert-style practice test for the International ESOL qualification (A1–C2).
