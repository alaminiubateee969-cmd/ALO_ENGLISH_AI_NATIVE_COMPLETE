# ALO Certify — Brand Guidelines

## Brand Name
**ALO Certify** — Certificate Auto-Send Engine

## Parent Brand
ALO Labs AgentOS (AI Agent Operating System)

## Logo
- **Icon:** Hexagon with orange (#FF6A00) outline, 3D blue (#003A8C → #0077FF) letter "A" inside
- **Wordmark:** "ALO" in bold orange + "Certify" in bold blue, sans-serif (Inter/Poppins)
- **Tagline:** "CERTIFICATE AUTO-SEND ENGINE" in gray, with blue line accents and orange dot

## Color Palette
| Color | Hex | Usage |
|---|---|---|
| Primary Orange | #FF6A00 | Brand, action buttons, highlights, ALO text |
| Primary Blue | #003A8C | System, trust, Certify text, backgrounds |
| Blue Gradient | #003A8C → #0077FF | 3D effects, logo letter A |
| Orange Gradient | #FF6A00 → #FFB300 | Accents, certificate borders |
| Gray | #6B7280 | Tagline, muted text |
| White | #FFFFFF | Background, cards, content |

## Typography
- **Primary Font:** Inter (body text, headings, UI)
- **Secondary Font:** Poppins (accents, certificate titles)

## Certificate Template
- A4 landscape format
- Orange + blue border (ALO Labs brand colors)
- Header: ALO Education logo + "Certificate of Practice Completion"
- Body: Student name, exam type, estimated score, band/CEFR, date
- Footer: Verification QR code + practice disclaimer
- Watermark: Hexagon logo at 10% opacity

## Logo Usage Rules
- Always use the official logo (do not recreate)
- Maintain color consistency (orange for action, blue for system)
- Do not alter logo proportions
- Minimum size: 32x32px for icon, 200px wide for full logo
- Clear space: at least 1x the hexagon height on all sides

## Brand Voice
- Professional, trustworthy, tech-forward
- Uses approved public wording only (ALO Evaluation System, Smart Score Report, etc.)
- Never claims official exam results
- Always includes practice disclaimer

## AI Agent Connection
- Certificate Agent (AGENT-CERTIFICATE-01) is the 21st AI Agent Employee
- Public label: "Smart Score Report" (students see this, not "Certificate Agent")
- Auto-executes: YES (can_auto_execute=1)
- Requires admin approval: NO (requires_admin_approval=0)
- Auto-generates certificate after every completed mock test
- Auto-sends email if SMTP configured
- Auto-syncs to CRM if connected
- Never blocks student from receiving their certificate
